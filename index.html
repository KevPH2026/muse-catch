FAQ

常见问题

现在收费吗？
Beta 期间完全免费，未来也会保持免费层。平台 AI 设有每用户每日用量保护；在 Settings 配置你自己的 Key（DeepSeek、MiniMax 等 OpenAI 兼容模型）则不限量。
开源版和云端版有什么区别？
功能同源。云端版开箱即用、多端同步；开源版（AGPL-3.0）克隆仓库即可自部署，数据、模型、网络全部在自己手里。两边用同一套 API Token 协议。
我的数据存在哪里？安全吗？
你的数据存放在你账号专属的独立数据库中，100% 归你，可随时删除。介意托管的话可以完全自部署——代码全部开源。
不装插件能用吗？
能。网页版登录后直接粘贴捕获；Telegram 绑定后转发消息即捕获；开发者可用 API Token 接入任何工作流。
AI 提炼用什么模型？可以换吗？
平台默认使用 MiniMax 模型自动提炼。你可以在 Settings 里换成自己的 DeepSeek / 任何 OpenAI 兼容模型，用自己 Key 的调用不受平台配额限制。
支持自动捕获哪些平台？
插件支持：任意网页（一键/快捷键/右键）、Twitter/X 点赞收藏、微信公众号阅读、微信读书划线。Telegram Bot 转发即存。API 可接入一切。
